This release updates Rails, the framework the app is built on, for its security fixes, and shortens the site's page titles so search results show them in full. Nothing changes in how you log an attack.

## Fixed

- **An updated Rails.** The app now runs Rails 8.1.4.1, which fixes published security advisories. By @crmne

## New

- **Titles that fit in search results.** English page titles end in "| Cluster Headache Tracker" like the other languages, and the homepage's title and description are short enough for Google to show whole. The diary template and the sample report each have one main heading. By @crmne
