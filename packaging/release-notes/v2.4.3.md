This release moves the app to Ruby 4.0.9 and updates the libraries that handle web requests and clean up HTML, all for security fixes. Nothing changes in how you log an attack.

## Fixed

- **A patched Ruby.** The server was still on Ruby 3.4.2. It now runs Ruby 4.0.9, which fixes regular-expression security problems. By @crmne
- **Updated security libraries.** rack, nokogiri, loofah, rails-html-sanitizer, addressable and net-ssh are at versions that fix published advisories. By @crmne
